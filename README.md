# 📚🎬 나의 작은 서재와 극장 — 홈 화면 런처

읽은 책과 본 영화·드라마를 기록하는 개인 대시보드(Google Apps Script 웹앱)의 **홈 화면 런처**입니다.

Apps Script 웹앱은 구글 래퍼 페이지 안에서 열려 `apple-touch-icon`을 iOS가 읽지 못합니다.
이 정적 페이지에서 **공유 › 홈 화면에 추가**를 하면 아이콘·이름이 그대로 적용되고, 실행하면 웹앱으로 바로 이동합니다.

- 웹앱 주소가 바뀌면 `index.html`의 `TARGET` 한 줄만 고치면 됩니다.
- 브라우저 탭에서 바로 열려면 주소 끝에 `?go`를 붙이세요.
- 데이터는 이 저장소에 없습니다(아이콘·런처만). `robots.txt`로 검색 노출을 막았습니다.
